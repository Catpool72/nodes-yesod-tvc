# Nodes of Yesod – plain TVC 64K version (by Kis Károly)

`yesod64k.cas` is a port of *Nodes of Yesod* for the plain Videoton TVC 64K (no extra video pages needed).
It is the work of **Kis Károly**, not of this repository's author: https://www.facebook.com/groups/206386136109760/user/1357985679

It is included here for convenience, as a companion to the 64K+ version in the repository root
(`yesod.cas`, which needs a TVC 64K+ with 128 KB). Only the tape image is provided; no source code was supplied.

The game itself belongs to its original authors.
